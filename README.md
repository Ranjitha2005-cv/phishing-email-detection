About the Project

Phishing Email Detection is a web-based project designed to help users identify potentially suspicious phishing emails and understand email security risks.

Features

- Simple and user-friendly interface
- Email input for checking suspicious content
- Detection results based on the implemented checking logic
- Awareness of phishing threats

Technologies Used

- HTML
- Netlify for deployment

Live Demo
https://vocal-melba-879b1c.netlify.app/

Purpose

The purpose of this project is to learn about phishing attacks, email security, and web development.
